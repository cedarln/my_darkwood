# v0.3 暗林 · 幸存夜

新增：

- 第二种敌人「掠夺者」：不跟你缠斗，专门绕到墙边扔燃烧瓶。火会烧塌木墙、篝火和木刺，还会往旁边的建筑爬；扔完瓶子才转近战。第四天起的夜袭和野外都可能出现。
- 灭火：背包里用掉一瓶水，能扑灭身边的火（解渴和灭火二选一）。下雨也会把火浇灭。
- 天气：会下雨了。雨幕挡视线、盖住脚步声，匪徒和掠夺者今晚多半不想出门。
- 随机事件：每天出门可能碰上敲门声、流浪商人、被困的狗、纵火者的脚印、空投、广播等十几种遭遇，多数要你当场做选择——选择时游戏是暂停的。
- 小地图上的橙点是火，赶紧去扑。
